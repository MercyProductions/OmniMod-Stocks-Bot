# DeFi Yield Research

Independent stablecoin lending-pool monitor. It reads the public DeFiLlama yields dataset, filters by protocol, chain, TVL, stablecoin flag, and minimum current APY, then ranks by the lower of current and 30-day mean APY so a falling rate is not hidden by its older average. Base and incentive APY are shown separately when the provider supplies both, including a base-only illustrative return when possible. If you provide a principal, holding period, and estimated round-trip costs, it calculates total-APY returns after those assumptions. It leaves net yield blank when costs are unknown; gas and exit conditions are never assumed to be free. Provider TVL is not withdrawable reserve liquidity. Ranking is a data screen, not a smart-contract audit or yield forecast. It does not connect a wallet, deposit, bridge, or compound.

Run with Node 22.9+; no account key is needed for public reads. The current provider response does not include a timestamp on every pool row, so the scanner marks upstream age as unknown and records only its own response retrieval time when that field is absent; it does not call such rows fresh. Data coverage and labels come from the provider and must be checked against the protocol's own current market page. DeFi lending can lose principal through depegs, contract bugs, governance changes, liquidity constraints, or provider errors. Advertised APY is variable.
