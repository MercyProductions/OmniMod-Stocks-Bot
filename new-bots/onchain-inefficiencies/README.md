# On-Chain Inefficiency Research

This independent project supports two read-only modes. `QUOTE_SOURCE=json` checks supplied timestamped quotes. `QUOTE_SOURCE=evm-v2` reads a configured list of circular routes through Uniswap V2-compatible Router02 `getAmountsOut` calls, all pinned to one RPC block. It estimates the cycle return after the configured USD gas cost and slippage reserve; the router's output already reflects its pool fees. A cycle must start and end in the same token. The adapter never requests a wallet, allowance, signature, or transaction.

The default configuration performs read-only Ethereum Mainnet smoke scans through the no-key PublicNode RPC and the documented Uniswap V2 Router02 deployment. It compares a nominal 100 USDC cycle through USDT and WETH back to USDC. This is a demonstration route, not a recommendation or evidence of profit. The sample's `$25` gas cost and 1% extra slippage reserve are deliberately conservative placeholders rather than live estimates; replace them with measured assumptions before interpreting net edge. Public RPC providers can rate-limit requests and can observe request metadata; set your own `RPC_URL` if you prefer another provider.

To configure other live reads, set `QUOTE_SOURCE=evm-v2` and add routes to `ROUTES_FILE` for the same chain. Each route needs `id`, `venue`, integer `chainId`, `routerAddress`, a circular token `path` of 3–8 contract addresses, `amountInRaw` as an integer string in the first token's smallest units, `inputUsd`, `gasUsd`, and `slippageReserveBps`. Optional `tokenSymbols`, `tokenDecimals`, and `assumptions` make output easier to interpret. The scanner checks `eth_chainId`, fetches a block number and its timestamp, rejects an invalid or stale block, then pins every quote to that block. Do not place RPC URLs containing credentials in chat, logs, or version control; `.env` is ignored.

The route file must list known, trusted router contracts. V2-compatible routers can differ in fee formulas, transfer-tax token support, and behavior; their quote method can still fail or misrepresent actual execution. The scanner does not inspect balances, allowances, token taxes, route simulation, atomic transaction feasibility, MEV, or whether a route is executable at the displayed size. A positive estimate is a research lead, not a realizable arbitrage. Uniswap's own router exposes `getAmountsOut` as a view quote for a given route [in its Router02 implementation](https://github.com/Uniswap/v2-periphery/blob/master/contracts/UniswapV2Router02.sol); that is not a guarantee of execution price.

Run with Node 22.9+. `examples/quotes.json` contains deliberately stale fixtures. The sample route is a public read-only smoke check with placeholder costs, not an investment signal. Liquidation and flash-loan strategies are not enabled.
