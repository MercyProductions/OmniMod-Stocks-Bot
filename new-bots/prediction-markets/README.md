# Prediction Markets

Independent market-data scanner for binary outcome markets. It checks active Polymarket markets with two outcome tokens, verifies book timestamps, reads best asks and bids in the provider's documented order, estimates the cost to buy equal shares from visible depth, and journals observations. For complete-set screens, it sizes to `NOTIONAL_USD` including the market's actual Polymarket taker fee schedule and refuses to surface a candidate if fee status/schedule or minimum order size is unknown. The all-in result still excludes settlement/redemption, gas/bridge, quote movement, and fill risk. Fresh sufficiently wide two-sided Polymarket spreads are surfaced as paper market-making watches using maker-fee treatment from the market schedule; displayed spread and size do not imply fills, queue position, or profit, and inventory/adverse-selection risk remain. For cross-platform comparisons, add an exact Polymarket slug and Kalshi ticker to `kalshi-matches.json` only after manually checking equivalent resolution rules. Reviews expire after `MAPPING_REVIEW_MAX_AGE_DAYS` (30 by default). Cross-platform prices remain gross-only and are labeled with fees unverified because Kalshi fee multipliers vary by product and the public listing response does not contain a complete effective fee schedule. No fuzzy matching is used.

Run `npm start` for recurring reads or `npm run scan` for a single pass with Node 22.9+. Public market reads need no private wallet key. `MIN_GROSS_EDGE` gates the gross complete-set spread, while `MIN_NET_EDGE_PER_SHARE` gates the fee-adjusted Polymarket estimate. Cross-platform comparison is top-of-book only and must be configured with manual mappings; its displayed edge is gross. Polymarket's fee schedule is read from each Gamma market object and applied to each visible ask level with five-decimal fee rounding. Review resolution rules, order-book depth, current fee terms, settlement details, and venue availability before any decision. Neither gross nor estimated net edge is locked profit. Snapshots append to the project's ignored `data/prediction-markets.jsonl` file.
